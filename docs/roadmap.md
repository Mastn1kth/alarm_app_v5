## Архитектурные планы

### База данных
- **V1**: SharedPreferences (JSON)
- **V2**: Hive (бинарный, быстрый)
- **V3**: SQLite (сложные запросы)
- **V4**: Room/SQLite + Cloud sync

### Локализация
- **V1**: Русский, English (базовый)
- **V2**: + Spanish, German, French
- **V3**: + Chinese, Japanese, Korean
- **V4**: + 20 языков

### Платформы
- **V1**: Android
- **V2**: iOS
- **V3**: Wear OS, Apple Watch
- **V4**: Web, Desktop
